# Обзор карточки заказа

Действующая карточка `Order360` открывается из списка заказов. В ней добавлены быстрые переходы к обзору, работам, запчастям, платежам, файлам и истории.

Обзор показывает клиента, технику, ответственных и сроки, общую таблицу работ и действующих запчастей. Стоимость и сумма оплаченного берутся из ответа CRM; отменённые запчасти исключены из таблицы. Полная история платежей включает возвраты, связанные оплаты, счета, документы, сотрудников и суммы с копейками. Платёжные действия продолжают использовать существующие серверные проверки.

На экранах до 760 px история открывается отдельной панелью. Escape, кнопка закрытия и фон закрывают панель, сохраняя карточку и комментарий; фокус возвращается к кнопке «История». Tab остаётся внутри открытой панели. Ошибка отправки комментария видна рядом с полем; текст сохраняется для повторной попытки. При переключении заказа комментарий предыдущего заказа не переносится.

Обновление того же заказа сохраняет карточку во время загрузки. Ответы устаревших запросов после переключения заказа или закрытия карточки игнорируются. Повторное открытие активного заказа обновляет его данные.

## Проверка

`web/e2e/order-card-overview.cjs` входит в обязательный браузерный CI. Все API перехватываются синтетическими ответами; запись допускается только в имитацию комментария. Проверяются полная история платежей, возврат с дробной суммой, исключение отменённых деталей, безопасное отображение текста, переходы с переводом фокуса, мобильная история, повторная отправка комментария и изоляция заказов при задержанном ответе.

Для запуска при работающем тестовом web-сервере и установленном Playwright:

```sh
BASE_URL=http://127.0.0.1:5173 node web/e2e/order-card-overview.cjs
```

Визуальное удобство на реальном рабочем месте требует отдельной оценки пользователем. Автоматические сценарии не заменяют такую оценку.
